## 已确认的首版规则

- 注册只用账号、密码，成功后自动登录；无需手机号、邮箱、验证码。已有账号正常登录。
- “寻书”采用书签交互输入口令，不是关键词在线爬虫搜索。
- 服务器预先保存书籍，口令映射至一本书；一个口令可供多个账号使用。
- 同账号重复领书不重复入架，不重置阅读进度。
- 已有书籍的领取仅建立个人书架关联，不重复下载、解析或复制正文。
- 未登录可输入口令并查看有限的书籍元数据；确认加入书架时登录/注册，随后继续领取。
- 书籍文件保存在服务器，账号书架与进度跟随账号；换设备登录可恢复。
- “书信领书”“心情选书”、复杂推荐、批量口令与外部自动抓取未确定为首版范围。

## 需要保持的数据边界

| 数据 | 归属 |
|---|---|
| Book、Chapter、封面、正文文件 | 服务器共享书籍数据 |
| Bookshelf | 当前账号与书籍的关联及该账号的阅读位置 |
| 口令实体（待设计） | 可查询的书籍映射与可用状态 |

保留 `(userId, bookId)` 唯一约束，用数据库层面的幂等处理并发领取；不只依赖先查后插。userId 来自认证上下文。领取前需检查口令可用及书籍存在，明确停用与并发领取语义。

正文接口必须检查账号是否已领取该书；JWT 合法不等于拥有所有书籍访问权。章节查询也需保证章节确实属于授权书籍。预览不返回正文。从个人书架移除不删除公共书籍或其他用户记录。

保持密码哈希、注册校验、账号唯一性、Token 校验；不因 UI 简化而移除后端约束。口令生成应足够难猜，并考虑查询防枚举；避免记录密码、完整 Token、有效口令。
